# Training Regimen

- Format: 4-day rolling split (Push / Pull / Legs / Rest), heavy 3 sets × 6 reps, 8-week cycle. Push and Pull run in circuits by movement number with primary lifts and dedicated machine backups.
- Pre-Workout Warm-Up & Conditioning (Every session: 1–3 blocks):
  - Abs: 3 sets Decline Crunches/Sit-ups, 3 sets Reverse Crunches + Bicycles, 3 sets Planks.
  - Stairmaster: 10 mins @ Level 4.
  - Treadmill: Incline ramp progression.
- Day 1: Push (~75 mins)
  - Chest: DB Press (55s) -> DB Incline Press (45s) -> DB Flys (30s–35s) -> Burnout push-up mechanical drop (Decline -> Flat -> Incline).
  - Triceps: Dips (25–30 lbs) -> DB Behind-Head Extensions (25 lbs) or Skullcrushers (60 lbs) -> Machine Pushdowns (175 lbs).
  - Shoulders: DB Shoulder Press (35s) -> DB Lateral Raises (25s) -> Machine Lateral Burnout (50–65 lbs).
- Day 2: Pull (~75 mins)
  - Back: Assisted Pull-Ups (65 lbs) -> Seated Close-Grip V-Bar Row (120 lbs) -> Rear Delt Machine (100 lbs).
  - Biceps: DB Curls (30s) -> Hammer Curls (30s) -> Cable / T-Grip Curls (60 lbs).
- Day 3: Legs (~40–45 mins)
  - Sequence: Leg Curls (120–125 lbs) -> Hack Squat (35s/side) -> Hip Abduction (130 lbs) -> Walking Lunges (10s–15s) -> Leg Extensions (130–160 lbs) -> Calf Machine (160 lbs).
  - Optional Finishers: Hip Adduction (130 lbs), Calf Raises (80 lbs), Glute Push (100 lbs).
  - Cool-Down: Sciatic nerve glides and stretching.
- Day 4: Rest / Active Recovery
  - Full day off lifting; optional 15–30 min Zone 2 cardio or mobility.
